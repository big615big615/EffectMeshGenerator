# Privacy

Effect Mesh Generator runs in the browser.

## Texture Files

When you choose an image file for texture preview, the file is loaded with a local browser object URL and used only for preview rendering.

The app does not upload selected texture files to a server.

## Generated Meshes

Generated mesh data is created in the browser. Exported OBJ files are downloaded directly from the browser.

## Analytics

This repository does not include analytics, tracking scripts, or remote logging.
