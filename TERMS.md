# Usage Terms

Effect Mesh Generator is a browser-based tool for generating effect meshes.

## Generated Meshes

Meshes generated and exported with this tool may be used freely in personal projects, commercial works, games, videos, and asset production.

Attribution is not required for generated meshes.

Credit or a link to Effect Mesh Generator is appreciated when practical, but it is optional.

## Textures and Uploaded Files

Texture files selected in the UI are loaded locally in the browser for preview only.

The app does not save selected texture files, upload them to a server, or include them in exported OBJ files.
