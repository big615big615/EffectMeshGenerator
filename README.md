# Effect Mesh Generator

ゲームエフェクト用メッシュ生成ツール

## クイックスタート

### セットアップ

```bash
npm install
```

### 開発サーバーの起動

```bash
npm run dev
```

`http://localhost:3000` でブラウザを開いてください。

### ビルド

```bash
npm run build
```

## 機能

- **リアルタイムプレビュー**: パラメータ変更時に3Dメッシュが即座に更新
- **カスタマイズ可能なパラメータ**:
  - `分割数`: メッシュの細かさ（3～32）
  - `厚み`: リボンの厚さ（0.1～2.0）
  - `長さ`: メッシュの長さ（1～10）
  - `曲線強度`: 曲線の強度（0～2.0）

- **自動回転**: メッシュが自動で回転して確認しやすく
